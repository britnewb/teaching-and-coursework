# teaching-and-coursework

## Contents

This repo contains samples of coursework documents, primarily for university-level Physics and Astrophysics. They were all written by Britta Hansen while at the University of Toronto.

## Compilation

Course documents are written in LaTeX. The Makefile can be used for each individual course by running 
    make directory/document_name
or all of the documents can be compiled at once by running 
    make all

make uses pdflatex and bibtex.
